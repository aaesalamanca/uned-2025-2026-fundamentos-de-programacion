# UNED 2025-2026 | Fundamentos de Programación

Prácticas realizadas en **C+-** para la asignatura de **Fundamentos de Programación** en la **UNED** durante el curso 2025-2026.

## Entorno de desarrollo

El repositorio está configurado para su uso con Visual Studio Code, Clang y ClangFormat, lo que permite:

- Resaltado de sintaxis para C y C++.
- Formateo automático del código al guardar los archivos.
- Compilación y depuración integradas.

## Requisitos previos

Antes de comenzar, compruebe que tiene instaladas las siguientes herramientas:

- [Visual Studio Code](https://code.visualstudio.com). Con las extensiones:
  - [vscode-cpptools](https://github.com/microsoft/vscode-cpptools)
  - [vscode-clang-format](https://github.com/xaverh/vscode-clang-format)
- [Clang](https://clang.llvm.org)
- [ClangFormat](https://clang.llvm.org/docs/ClangFormat.html)

## Ejecución y depuración

Para ejecutar, probar o depurar cualquiera de las prácticas:

1. Abra el repositorio con Visual Studio Code.
2. Abra el archivo `*.cpp` que desee ejecutar.
3. Presione `F5` para compilar, ejecutar y depurar el programa.
